# OmniCellAgent Session Folder Structure

This note documents the session-output layout used by OmniCellAgent, using
`webapp/sessions/AD-test-2/` as the concrete example. The omics outputs are
generated by `tools/omic_tools/omic_fetch_analysis_workflow.py` and
`tools/omic_tools/omic_analysis_components.py`; the final markdown/PDF reports
are saved by the agent/webapp layer in `agent/` and `webapp/UI/`.

## What a Session Represents

A session folder is the filesystem record for one user-facing analysis run.
The folder name is the `session_id` supplied to the agent or generated by the
UI/CLI. For example:

```text
webapp/sessions/AD-test-2/
```

For omics tasks, the session is a single-cell RNA-seq cohort analysis, not a
bulk RNA-seq analysis. In `AD-test-2`, the query resolved to Alzheimer's
disease brain cells, with a disease-vs-normal label mapping:

```text
normal -> 0
Alzheimer's Disease -> 1
```

Biomedically, that means downstream differential expression compares cells from
the reference/control class against cells labeled as Alzheimer's disease. The
rows in the expression matrix represent individual cells or nuclei, while
features represent molecular measurements mapped back to gene/transcript names.

## Run Stages and Outputs

### 1. Agent Creates the Session

Files/functions involved:

- `agent/simple_magentic_agent.py`
- `agent/langgraph_agent.py`

The agent creates `webapp/sessions/<session_id>/` and passes that path into the
omics workflow as `session_dir`. This is why all downstream analysis products
land under the same session folder.

The agent also saves report files after the tool and research agents finish:

- `report_<timestamp>.md`: final markdown report.
- `report_<timestamp>.pdf`: compiled PDF version when PDF generation succeeds.
- `report_revised_<timestamp>.md` / `.pdf`: revised report produced from user
  feedback without rerunning the full omics pipeline.

Some historical or benchmark scripts may use a hyphenated revised-report name
such as `report-revised_<timestamp>.md`.

### 2. Omics Workflow Fetches the scRNA-seq Cohort

Main function:

- `omic_fetch_analysis_workflow(...)`

Data-fetch function:

- `omic_fetch_with_new_loader(...)`

The workflow queries OmniCellTOSG through `CellTOSGDataLoader`, using extracted
or direct parameters such as disease, cell type, organ, tissue, gender, and the
comparison label.

Key files:

- `labels.csv`: metadata for the selected cells. In `AD-test-2`, columns include
  dataset ID, suspension type, cell type, tissue, disease, age/stage fields,
  sex, source matrix path, and sample index.
- `labels_full_disease.csv`: expanded disease-label metadata emitted by the
  loader for the disease comparison.
- `label_mapping_disease.csv`: maps biological label names to integer classes
  used by the model/workflow, e.g. normal/control as `0` and Alzheimer's
  disease as `1`.
- `expression_matrix.npy.lrz`: compressed expression matrix. The uncompressed
  `expression_matrix.npy` is removed after compression because it can be very
  large.
- `labels.npy.lrz`: compressed numeric label vector.

Biomedical meaning:

- `labels.csv` is the sample provenance table. It tells you what each cell is:
  source study, brain region, disease label, cell type, sex, and age/stage.
- `expression_matrix.npy.lrz` is the quantitative molecular data matrix used for
  expression and differential-expression calculations.
- `label_mapping_disease.csv` defines which biological group is treated as the
  reference group and which is treated as disease in the differential-expression
  contrast.

### 3. Workflow Computes Top Expressed Features

Main function:

- `compute_top_genes(...)`

Output:

- `top_genes_by_expression.csv`

Columns:

- `rank`: rank by average expression across the selected cohort.
- `gene_index`: feature index in the expression matrix.
- `mean_expression`: cohort-level mean expression for that feature.

Biomedical meaning:

This file is a quick abundance summary. It does not by itself say a gene is a
biomarker or disease-specific; it only says the feature has high mean expression
in the fetched single-cell cohort.

### 4. Differential Expression Analysis

Main function:

- `omic_analysis(...)`

Differential-expression function:

- `perform_unpaired_differential_expression(...)`

The workflow splits the expression matrix into two groups using `Y == 0` and
`Y == 1`, aggregates features to gene names, and runs an unpaired
Mann-Whitney/rank-based differential expression test. It then applies
Benjamini-Hochberg FDR correction and computes log2 fold change plus effect
size.

Directory:

```text
differential_expression/
```

Files:

- `unpaired_differential_expression_results.csv`: full DE table for all tested
  genes.
- `significant_genes_by_fdr.csv`: significant genes sorted by adjusted p-value.
- `significant_genes_by_fc.csv`: significant genes sorted by absolute log2 fold
  change.
- `significant_upregulated_genes.csv`: significant genes with positive log2 fold
  change.
- `significant_downregulated_genes.csv`: significant genes with negative log2
  fold change.

Common columns:

- `Name`: gene symbol/name.
- `log2_fold_change`: disease/reference expression ratio on log2 scale.
- `effect_size`: standardized difference between the two groups.
- `p_value`: raw statistical-test p-value.
- `FDR`: multiple-testing adjusted p-value.
- `is_significant`: whether the gene passed the configured FDR threshold.
- `abs_log2_fc`: absolute fold-change magnitude.

Biomedical meaning:

- Positive `log2_fold_change` means higher expression in the disease-labeled
  group (`Y == 1`) than the reference/control group (`Y == 0`).
- Negative `log2_fold_change` means lower expression in disease than control.
- FDR is essential because thousands of genes are tested; raw p-values alone are
  not enough for gene discovery.
- Up/down gene lists are the basis for pathway and disease-enrichment analyses.

### 5. Volcano Plots

Plot function:

- `create_volcano_plot(...)`

Directory:

```text
volcano_plots/
```

Files:

- `volcano_plot.png`: stricter static volcano plot.
- `volcano_plot.html`: interactive Plotly version of the stricter plot.
- `volcano_plot_permissive.png`: more permissive threshold view.
- `volcano_plot_permissive.html`: interactive Plotly version.

Biomedical meaning:

A volcano plot places effect size on the x-axis and statistical confidence on
the y-axis. Genes far left or right with high y-values are stronger candidates
for disease-associated downregulation or upregulation.

### 6. Enrichr Pathway and Disease Enrichment

Main functions:

- `perform_enrichment_analysis(...)`
- `enrichr_analysis(...)`
- `create_enrichment_summary(...)`

Directory:

```text
enrichment_results/
```

In `AD-test-2`, the workflow created one directory for each gene set:

```text
enrichment_results/
├── Alzheimer's_disease_all_regulated/
├── Alzheimer's_disease_up_regulated/
└── Alzheimer's_disease_down_regulated/
```

Each gene-set directory contains one CSV per queried Enrichr database, plus a
JSON dump and a text summary:

- `all_enrichment_results.json`: complete Enrichr response for that gene set.
- `summary.txt`: readable top-term summary by database.
- `GO_Biological_Process_2021_results.csv`: enriched biological processes.
- `GO_Molecular_Function_2021_results.csv`: enriched molecular functions.
- `GO_Cellular_Component_2021_results.csv`: enriched cellular compartments.
- `KEGG_2021_Human_results.csv`: enriched KEGG pathways.
- `Reactome_2022_results.csv`: enriched Reactome pathways.
- `WikiPathways_2019_Human_results.csv`: enriched WikiPathways pathways.
- `MSigDB_Hallmark_2020_results.csv`: enriched hallmark signatures.
- `DisGeNET_results.csv`: disease associations.
- `OMIM_Disease_results.csv`: curated Mendelian disease associations.
- `OMIM_Expanded_results.csv`: expanded OMIM associations.
- `Human_Phenotype_Ontology_results.csv`: phenotype associations.
- `Jensen_DISEASES_results.csv`: text-mined/knowledgebase disease terms.
- `GTEx_Tissue_Expression_Up_results.csv`: tissues where genes are normally
  enriched.
- `GTEx_Tissue_Expression_Down_results.csv`: tissues where genes are normally
  depleted.

Common enrichment columns:

- `Rank`: Enrichr rank.
- `Term`: pathway, phenotype, disease, or tissue term.
- `P-value`: raw enrichment p-value.
- `Odds Ratio`: overrepresentation strength.
- `Combined Score`: Enrichr combined ranking score.
- `Genes`: submitted DE genes overlapping the term.
- `Adjusted P-value`: multiple-testing adjusted enrichment p-value.

Biomedical meaning:

Enrichment asks whether a list of DE genes is overrepresented in known pathways,
phenotypes, tissues, or diseases. In the `AD-test-2` KEGG all-regulated output,
terms such as ribosome, Parkinson disease, prion disease, and Huntington disease
reflect shared molecular programs among neurodegenerative contexts, but they
should be interpreted as pathway/gene-set overlap rather than a diagnosis.

### 7. Enrichment Bar Plots

Plot function:

- `plot_selected_enrichment(...)`

Directory:

```text
enrichment_results/enrichment_plots/
```

Files in `AD-test-2`:

- `KEGG_2021_Human_all_regulated.png` / `.pdf`
- `KEGG_2021_Human_up_regulated.png` / `.pdf`
- `KEGG_2021_Human_down_regulated.png` / `.pdf`
- `Reactome_2022_all_regulated.png` / `.pdf`
- `Reactome_2022_up_regulated.png` / `.pdf`
- `Reactome_2022_down_regulated.png` / `.pdf`

Biomedical meaning:

These figures summarize the highest-ranked pathway terms for each gene set. The
split between all/up/down genes helps distinguish pathways activated in disease
from pathways suppressed in disease.

### 8. KEGG R Visualizations

Caller:

- Step 5 of `omic_fetch_analysis_workflow(...)`

Script:

- configured as `enrichment.kegg_script` in path configuration.

Directory:

```text
plots/
```

Files:

- `kegg_dotplot.png`: static KEGG dot plot.
- `kegg_dotplot.html`: interactive KEGG dot plot.
- `pathway_combined_plot.png`: static combined pathway visualization.
- `pathway_combined_plot.html`: interactive combined pathway visualization.
- `kegg_dotplot_files/`: HTML-widget support assets.
- `pathway_combined_plot_files/`: HTML-widget support assets.

Biomedical meaning:

The KEGG dot plot emphasizes pathway-level enrichment strength and significance.
The combined plot gives a broader view of pathway terms and gene overlap,
helping connect individual DE genes to biological systems such as metabolism,
protein synthesis, mitochondrial function, immune signaling, or
neurodegeneration pathways.

## Quick Interpretation Guide

Use `labels.csv` first to verify the biological cohort: disease, tissue, cell
type, sex, age/stage, and source dataset.

Use `label_mapping_disease.csv` to confirm the contrast direction before
interpreting fold changes.

Use `unpaired_differential_expression_results.csv` for the full statistical
record, and the significant-gene files for focused downstream interpretation.

Use volcano plots to visually triage high-effect, high-confidence genes.

Use enrichment CSVs and plots to move from gene-level signals to biological
processes, pathways, phenotypes, and disease associations.

Use reports as the narrative layer: they should cite the session artifacts, but
the CSVs and matrices are the primary computational record.
